# Screenshots

Drop store/GitHub captures here and they'll appear in the main `README.md`.

Suggested set (Chrome Web Store accepts **1280×800** or **640×400** PNG/JPG):

| File | What to capture |
|---|---|
| `side-panel.png` | Side panel, Midnight theme, timer running, a couple of tasks (one with an overdue deadline). |
| `floating-widget.png` | The floating widget over a real website, with fireflies visible. |
| `themes.png` | The three themes side by side (Midnight / Daylight / Sage). |
| `daylight.png` | Daylight (light) theme — timer + tasks. |
| `sage.png` | Sage theme — timer + tasks. |
| `settings.png` | Settings: themes, sounds, durations and toggles. |

Tip: the Web Store shows the **first** screenshot most prominently — lead with the one that best conveys "calm focus + fireflies."
